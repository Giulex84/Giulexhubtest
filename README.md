# Arena Test (Pi Network Testnet)

A memory arena game demonstrating **U2A** (Premium unlock) and **A2U** (Combo rewards) flows.

## Features
- **Name**: Arena Test
- **Premium**: 1.0 Test-Pi for 10 levels of infinite lives.
- **Reward**: 0.3 Test-Pi sent to user upon achieving a Triple Combo.
- **Scalability**: 10 levels of progressive difficulty.
