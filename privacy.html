Privacy Policy

Last updated: September 7, 2026

Arena Test is a Pi Testnet application used to test authentication, Test-Pi payments, gameplay and Test-Pi rewards.

Pi authentication

After you authorize Pi sign-in, Arena Test sends the Pi access token to its backend. The backend validates that token with Pi Network's /v2/me endpoint and uses the app-specific Pi UID and authorized username. Client-provided identity data is not treated as the server source of truth.

Testnet payments

For Premium purchases and Test-Pi rewards, Arena Test processes Pi payment identifiers and blockchain transaction identifiers needed to approve, complete and verify transactions. Test-Pi has no real-world value.

Persistent records

Arena Test stores the minimum server-side records needed to restore Premium, persist gameplay level/lives/score under the verified Pi UID, prevent duplicate payment fulfillment, rate-limit Test-Pi rewards and record successful reward fulfillment. Card layout and transient in-session UI state are not treated as authoritative persistent records. Wallet passphrases and private keys are never requested from users.

Service providers

Arena Test uses Pi Network for authentication and Testnet payments and a server-side Redis-compatible key-value store for entitlement, gameplay and reward-protection records. Server credentials and the Testnet app-wallet signing seed remain server-side.
